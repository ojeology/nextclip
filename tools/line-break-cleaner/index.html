How to use the line break cleaner.

What it does. Fixes inconsistent line breaks in pasted text.

How to use it. Paste text with stray or missing line breaks and get a clean result. Great for text pasted from PDFs or web pages.

Why it matters. Pasted text often inherits odd breaks. Cleaning them makes a document reliable before editing.
