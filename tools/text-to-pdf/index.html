How to use the text to pdf.

What it does. Turns plain text into a clean, downloadable PDF.

How to use it. Paste or write text and click to create a PDF. Great for a first draft, a simple report or a shareable version of notes.

Why it matters. PDFs preserve formatting and are easy to send. Making one from text in the browser is quick and needs no app.
