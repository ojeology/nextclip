How to use the images to pdf.

What it does. Combines JPG or PNG images into a single PDF, one image per page.

How to use it. Choose one or more images and the tool builds a PDF with each on its own page.

Why it matters. Combining scans, screenshots or photos into one shareable PDF is a common task an editor or client may ask for.
