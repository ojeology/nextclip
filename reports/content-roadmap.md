# NEXTCLIP content roadmap — first quality expansion cycle

This roadmap uses the current catalogue and is intentionally focused on pages that can be useful without inventing release information, credits, ratings, or news.

## Ten priority movie pages for editorial enrichment

1. **Interstellar** — already connects naturally to a high-intent “movies like” guide and supports science-fiction discovery.
2. **Dune: Part Two** — strong existing description, connected explainer, and useful science-fiction topic relationship.
3. **The Dark Knight** — a recognisable entry point for superhero/action discovery; enrich only with original analysis or verified information.
4. **Avengers: Endgame** — supports the existing Marvel collection and superhero recommendation content.
5. **Spider-Man: No Way Home** — supports superhero and event-movie discovery.
6. **Parasite** — supports Korean cinema recommendations and accessible film-discussion content.
7. **Train to Busan** — supports Korean cinema and horror discovery.
8. **Get Out** — supports the modern-horror recommendation route.
9. **Mad Max: Fury Road** — supports action/adventure recommendation content.
10. **Spirited Away** — supports animation/fantasy and recommendation discovery.

## Ten priority editorial briefs

These are briefs, not automatically published articles. Each must be researched, fact-checked and editorially reviewed before its status changes to `published`.

1. **Movies like Inception** — recommendation guide linked to Inception, Tenet, The Matrix and Arrival.
2. **Best action movies in the current NEXTCLIP catalogue** — a short, reason-led list, not a ranking based on invented popularity.
3. **Best superhero movies in the current catalogue** — linked to the Marvel topic and relevant title pages.
4. **A spoiler-light guide to the ending of The Matrix** — publish only after a human editorial review of the explanation.
5. **Why Parasite changes tone so sharply** — analysis rather than a copied plot summary.
6. **How to start with Studio Ghibli films in the catalogue** — recommendation guide based on available titles.
7. **What makes Train to Busan a strong entry point for Korean cinema** — original analysis.
8. **A practical guide to choosing a horror movie by mood** — expansion of the existing starter route.
9. **The Marvel movies topic: a viewing path for new viewers** — only using titles available in the catalogue.
10. **A verified Nigerian cinema starter guide** — do not publish until a real, reviewed Nigerian movie set is added to the catalogue.

## Five priority topic hubs

1. **Marvel Movies** — already published; enough real catalogue coverage.
2. **Space and Big Ideas** — already published; ties together science-fiction titles and related reading.
3. **Action Essentials** — publish after a short editorial introduction and a curated collection are reviewed.
4. **Modern Horror** — publish after the existing horror recommendation articles are checked and linked.
5. **Korean Cinema** — publish after the catalogue/title relationships have been editorially reviewed.

## Intentionally deferred

- **Nigerian Movies:** not published as a hub yet because the current catalogue does not contain a verified, useful Nigerian movie set.
- **Upcoming Movies / Movie News:** not published until release/news claims can be verified and given real publication/update information.
- **Actor and director pages:** deferred until verified person data is available.
