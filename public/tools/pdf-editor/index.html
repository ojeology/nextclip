About this tool

How to use the pdf editor.

What it does. Lets you edit a PDF's pages — rotate, delete, reorder — entirely in your browser.

How to use it. Open a PDF, then use the controls on each page to rotate, remove or move it. Export a new PDF when you're happy. Nothing is uploaded.

Why it matters. A quick fix to a PDF — a rotated scan, a page to drop — shouldn't need uploads or an account. Doing it client-side keeps it private.
