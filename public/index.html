HOW WE WORK4 RULES
1. Read the guideline

Every dossier quotes pay, word count, eligibility from the official guideline and links to it.

2. Date everything

Last-verified on every market, reviewed on every guide. Stale pages are marked.

3. No pop-ups, ever

Trust is a feature. If we break it with a pop-up, you leave.

4. Tools stay private

What you type into a tool stays in your browser. No upload, no account, no server log.
