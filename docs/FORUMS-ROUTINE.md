# BRYME forums routine — answer-first, never link-dropping (B6)

**Owner:** house ops · **Cadence:** 2 h/week · **Started:** 2026-09-29
**Goal:** reputation + referring domains in the communities where our own research
shows **forum-dominated SERPs** (selection criterion 2 in
`LOW-COMPETITION-TOPIC-RESEARCH.md` — the Tier-B topics were picked from exactly
those queries). The companion retention surface is the existing `/newsletter/`
digest: forums feed it by reputation, not by promotion.

## Policy (unchanged from the prep pack, `TRACK-B2-B6-PREP.md`)

- Participate as a person. Disclose affiliation only if a community asks.
- Link only when a page **genuinely answers the thread**. No posting the same link
  in multiple communities in one week.
- Text-first: many communities ban links outright (r/personalfinance, many
  r/homeowners threads) — answer in-text; link only on explicit ask.
- Never quote a figure the site's own data cannot produce (house rule: no
  fabricated statistics). Our own datasets (142-record publications DB,
  State-of-Paid-Writing 2026) are the citable assets.

## Weekly routine (2 h)

1. **Scan (45 min):** search each community for the last week's threads matching
   our Tier-B topics (the backlog slugs in `LOW-COMPETITION-TOPIC-RESEARCH.md`
   are the query map). Save candidates.
2. **Answer (60 min):** 3–5 substantive answers. Text first. ≤1 link per week
   total, only on explicit ask or where a page is genuinely the answer.
3. **Log (15 min):** record answers + any referral traffic in
   `docs/referring-domains-log.csv` (same tracker as the HARO routine).

## Success metrics (monthly)

- Substantive answers (target 12–20/month)
- Threads where our answer was the accepted/top reply (leading indicator)
- New referring domains from community links (expected near zero early —
  reputation is the product; links are a by-product)

## Ground rules (house)

- Dates on everything; if a community cites our figure and the dataset moves,
  we correct the thread proactively (same protocol as `HARO-ROUTINE.md`).
- No betting content, no piracy, no fabricated data — in every community,
  disclosed or not.
- The answer must stand alone without the link. If it cannot, it is not an
  answer, it is a pitch — and pitches stay out.
